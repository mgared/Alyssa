# Photos

Drop photos here. Any image that is missing shows a soft tonal placeholder instead.

- `hero-1.jpg`, `hero-2.jpg`, `hero-3.jpg` — home page slideshow (wide, landscape)
- `alyssa.jpg` — portrait for the About page (portrait orientation)
- `projects/<project-slug>/cover.jpg` — portfolio grid thumbnail (portrait, 4:5)
- `projects/<project-slug>/1.jpg`, `2.jpg`, ... — project page gallery

Project names, slugs and image lists live in `src/data/site.js`.
